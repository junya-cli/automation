# 売れるセールスレター マスタープロンプト

『The.IMPACT 〜1の労力で100の成果を〜』（なまいきくん）の第1〜7章を読み込み、セールスレターを書くための考え方・型・技法を、AIがそのまま実行できる1本のプロンプトにまとめたものです。

| ファイル | 内容 |
|---|---|
| `MASTER_PROMPT.md` | AIに貼り付ける本体。末尾にヒアリングシート付き |
| `README.md` | このファイル（使い方と設計） |

## 使い方

1. `MASTER_PROMPT.md` を全文コピーする。
2. 末尾のヒアリングシートを埋める（殴り書きでOK。【必須】だけでも動く）。
3. AIに送信する。
   - **対話モード（推奨）**：戦略シートを出したところで一度止まる。コンセプト・証拠・読者像を確認し、「OK」か修正指示を返すと本文に進む。
   - **おまかせモード**：最後まで一気に書く。
4. 出力された【要証拠】【要確認】の箇所を、本物の素材に差し替える。

長文の出力に強いモデルでの利用を推奨します。途中で切れたら「続き」と送ってください。

### 部分的な使い方（プロンプトを貼った後に追加で指示）

- 「ブロック12のブレットを、切り口を変えて20本書き直して」
- 「冒頭のフックを、忠告型・物語型・矛盾型で1本ずつ」
- 「このレターを第5部のチェックで添削して」＋既存のレターを貼り付け
- 「1行版だけ10案」
- 「戦略シートの1-4（本音の欲望）だけをもっと深掘りして」

## プロンプトの設計

元ファイルの主張の核は「文章は書く前に8割決まる」です。そのため、本文を書く前の **STEP 1（戦略シート）** に最も多くの分量を割いています。

| プロンプトの部 | 元ファイルの該当箇所 |
|---|---|
| 第1部　判断の大原則 | 1章（誰が×何を×どう書くか、2:8の法則、良い文章＝目的を達成する文章）、3章（コンセプト×証拠）、6章（教育ロジックの一貫性、レターは教育の総集編） |
| 第2部 STEP 1　戦略シート | 2章（「誰が」の文脈）、3章（目的からの逆算、売れる切り口、30秒テスト、信憑性を高める10要素、本音欲望の3テンプレ、欲の掛け合わせ）、4章（思い込みを使え、セールスの黄金方程式）、5章（コンテンツ＝魔法の杖、成功要因の設定、2段手前のつまずき、世界の二分化）、6章（リサーチ項目） |
| 第3部　16ブロック構成 | 6章（セールスレターの構成）、7章（掌握のレター解説） |

| 第5部　添削チェック | 5章（N式19項目）、6章（完成後にN式で磨く） |
| 第6部　納品物 | 3章（1行で売る、環境に教育させる一言）、1章（ライティング以前の打ち手） |

## 元ファイルから意図的に変えた点

- **証拠は本物だけを使う設計にしています。** 元ファイルの核である「証拠こそ最強」を、捏造ではなく実在の証拠で満たす方向に寄せ、不足は【要証拠】として見える化します。
- 限定・締切・同時購入者数などは、事実として存在するものだけを書きます。
- 「誰でも」「必ず」といった断定は使わず、元ファイルの「〜を極めてしまえば」という仮定の表現で強さを出します。
- 未成年や違法行為を題材にした元ファイルの事例は採用していません。
- 景品表示法・特定商取引法・ステマ規制などの確認ポイントを、納品物に含めています。

いずれも売る力を落とすためではなく、炎上・返金・アカウント凍結で売上がゼロになるのを防ぐための変更です。
