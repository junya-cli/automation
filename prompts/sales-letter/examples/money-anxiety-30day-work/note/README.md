# noteに貼る（販売記事）

セールスレター v4（`../sales_letter.md`）を、noteの販売記事向けに直したものです。
貼り付け用のページ（コピーボタン・画像・公開前チェックつき）：https://claude.ai/artifact/3vYgmETKn9hLKf6xbNfmeP

## ファイル

| ファイル | 中身 |
|---|---|
| `note_body.html` | 本文（無料部分）。noteの本文欄に貼る |
| `note_paid.html` | 有料エリア。有料ラインの下に貼る |
| `images/00_midashi.png` | 見出し画像（1280×670） |
| `images/02_5types.png` 〜 `06_plan.png` | 本文の【画像①〜⑤】に入れる画像 |
| `kit.html` | 貼り付け用ページ（`make_kit.py` で作成） |
| `make_kit.py` | 本文を直したら `python3 note/make_kit.py` で作り直す |

画像のうち、見出し画像・5タイプ・3つの習慣は `../product/pdf/src/note_images.py` で作っています。

## 手順

1. タイトルを決めて、見出し画像を設定する
2. 本文をコピーして貼る（見出し・太字・箇条書きはそのまま入る）
3. 冒頭の6段落を中央寄せにする
4. 【画像①〜⑤】の行を画像に差し替える
5. 本文の最後（出典の下）に有料ラインを置き、有料エリアを貼って、PDFを添付する
6. 【要確認】の行を直すか消し、価格を決めて公開する

## v4（`sales_letter.md`）からnote用に変えたところ

- 購入ボタン3か所 → noteの有料ライン1か所。本文の途中には「購入は、この記事のいちばん下のボタンから」を1行
- 価格の記載を本文から削除（noteの公開設定で表示されるため）
- 5タイプと3つの習慣は、画像に文字を入れたので、本文の重複を削った
- 「声」の見出しは、声が集まるまで置かない
- 有料エリア（PDF・書き込みノート・購入者限定LINE・今日やること）を新しく書いた
