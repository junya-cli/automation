日付は例（給料日が25日、第1期のスタートが15日、31日まである月）。【】は差し替える所。
吹き出しは1通につき3つまで。画像は `note/images/` のものを使います。
文面を直すときは `messages.py` を直して `python3 launch/make_launch.py` で作り直してください。

## L0　あいさつ＋お金のクセ診断

- **いつ**：友だち追加のとき（自動）
- **どこ**：LINE（見込み客）
- **ねらい**：診断で「自分のタイプが分かった」という小さな体験をしてもらう。結果を返信してもらうと、その後の配信が読まれやすくなる
- **メモ**：「すべて読みます」と書くなら、読む時間を確保する。難しければ「いただいた返信は、配信の参考にします」に変える

**吹き出し1**

```
友だち追加、ありがとうございます。アオです。

このLINEでは、毒親育ちの人の「お金の不安」を、少しずつゆるめるヒントをお届けします。

まずは、プレゼントです。
```

**吹き出し2**

```
▼ お金のクセ診断（20問・5分）
【診断PDFのURL】

最近1か月のあなたに、0〜3で答えて、点数を足すだけ。
お金のクセの「5つのタイプ」のうち、あなたに強く出ている2つが分かります。
```

**吹き出し3**

```
結果が出たら、あなたの2タイプを、このトークに送ってもらえたらうれしいです。
（例：「人に出しすぎ・見ないふり」）

いただいた返信は、すべて読みます。
もちろん、送らなくても大丈夫です。
```

- **メモ**：ここで集めた質問を、L7（よくある質問）に使う

**吹き出し1**

```
こんばんは、アオです。
診断、やってみましたか？

```

**吹き出し2**

```
家計簿アプリを入れた。節約の本も読んだ。
それでも続かなかった。
続いても、「足りない」は消えなかった。

もしそうなら、あなたの意志が弱いからではありません。

家で、親からお金の使い方を教わった人は、100人のうち15人ほど。
でも、教わっていなくても、子どもは見て覚えます。

「うちはお金がない」が口ぐせの家。
お金の話になると、空気が重くなる家。

そこで覚えた「お金のルール」が、大人になった今も、静かに動いているんです。

**吹き出し3**

```

だから、責めて直すものではなく、少しずつゆるめていくもの。

お金のことで、いま一番聞きたいことがあれば、1つだけ送ってください。近いうちに、まとめてお答えします。

次回は、僕がそれに気づいたきっかけの話です。
たった650円が、出せなかった話。
```

## L2　650円が、出せなかった

- **いつ**：4日（教育②）21:00
- **どこ**：LINE（見込み客）
- **ねらい**：型の「変化」：アオの物語。受講者の声がまだ無いので、本人の変化を事例にする。最後に「安心ライン」という考え方を渡す
- **メモ**：【要確認】の1〜2行は、物語の説得力がいちばん上がる所。書けない場合は行ごと消す

**吹き出し1**

```
こんばんは、アオです。
今日は、僕の話をさせてください。

社会に出てすぐの頃、僕の給料は20万円ちょっとでした。
残高が5万円を切って、口座を見るのが、どんどん怖くなっていきました。

本当は、800円のラーメンが食べたい。
なのに、手に取るのは150円のカップラーメン。

たった650円の差なのに、自分のためだと、どうしても出せなかったんです。
```

**吹き出し2**

```
変わり始めたのは、「アダルトチルドレン」という言葉に出会って、お金のクセも「家で覚えたルールかもしれない」と思えたときからでした。

【要確認：そのあと実際にやったことを1〜2行】

初めて「使っていい」と思えたのは、値引きのお惣菜ではなく、1,500円のお寿司を買えた日です。

そして、あるときから、引き落としのあとに残高を見ても、胸がざわつかなくなりました。
```

**吹き出し3**

```
1つ、知っておいてほしいことがあります。

資産を1億円以上持っている人たちでも、約4人に3人が「完全に幸せになるには、今の2倍以上必要」と答えた、海外の調査があります。

お金が増えても、「足りない」は消えないことがある。
足りないのは、お金だけではなく、「ここまであれば大丈夫」という線なんです。

あなたは今、その金額を言えますか？

次回は、この線が引けたあとの「30日後の、ある1日」の話をします。
```

## L3　30日後の、ある1日

- **いつ**：6日（教育③）21:00
- **どこ**：LINE（見込み客）
- **ねらい**：型の「手に入れた後」：その先の景色、3つの習慣（中身は伏せる）、「前にもやった」への答え、発売と第1期の予告
- **画像**：`note/images/03_3habits.png`
- **メモ**：画像は2つ目の吹き出しの前か後に。発売日の曜日を入れる

**吹き出し1**

```
こんばんは、アオです。
今日は、少し先の話です。

給料日の翌日。
何もしなくても、急な出費のためのお金が、自動で少しずつ別の口座に移っていく。

お金のことを考えるのは、週に1回、5分だけ。

週末の朝、好きなパン屋さんの朝ごはんを、罪悪感なしで食べている。

引き落としのあとに残高を見ても、胸がざわつかない。
```

**吹き出し2**

```
そのためにやることは、3つだけです。

① 見る：週に1回、5分だけ
② 分ける：給料日に、使う前に先に分ける
③ ひと呼吸：「もし〇〇になったら、△△する」を1文だけ

細かい家計簿も、我慢の節約も、しません。
親を許す必要も、ありません。

「それなら前にもやった」と思った方へ。
同じ「見る」でも、ため込みタイプと見ないふりタイプでは、練習することが逆です。
診断で分かった2タイプによって、30日で特にやることが変わります。
```

**吹き出し3**

```
この30日を、1冊のワークにしました。

『毒親育ちのお金の不安がなくなる小さな習慣』
1日5分・書き込み式・118ページ

9日（〇）の20時に、noteで発売します。

そして今回は「第1期」として、買ってくださった方と、同じ日に一緒に始めます。
くわしくは、発売の前日にお知らせしますね。
```

## L7　いただいた質問に答えます

```
こんばんは、アオです。

```

```

Q. 実家に仕送りをしています。減らさないといけませんか？
減らすかどうかは、あなたが決めることです。

Q. 忙しくて、続けられるか不安です
