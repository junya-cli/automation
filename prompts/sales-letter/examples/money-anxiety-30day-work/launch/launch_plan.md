## 2. オファー

### 第1期「一緒に始める30日」

**10月21日（水）23:59までに購入した人は、10月22日（木）に全員でDay0を始めます。**

| 項目 | 内容 |
|---|---|
| 商品 | 30日ワーク（PDF・118ページ）＋書き込みノート＋LINEでのサポート |
| 価格 | 2,980円 |
| 第1期特典① | 30日間の伴走メッセージ（Day0・7・13・20・28・30の6回。つまずきポイントの日に届く） |
| 第1期特典② | **あなたのタイプ専用メッセージ**：診断の2タイプの番号を「タイプ25」のように送ると、その組み合わせ専用のメッセージが自動で届く（15通り。`type_cards.md`） |
| 締め切り | 10月21日（水）23:59 |
| 締め切りの理由 | 10月22日に全員で始めるため。同じ日に始めるから、つまずきやすい日に同じタイミングで声をかけられる |
| 日程の良さ | 10月31日にDay9「先取りを自動にする」が終わる → 11月25日の給料日を、お金を分ける仕組みが動いた状態で迎えられる |
| 締め切りのあと | ワークは同じ2,980円で買える。第1期の特典だけがつかない |

**特典②を自動応答にした理由**：「アオからの一言」を手で書くと、購入数が増えるほど手間が増えます。2タイプの組み合わせは10通り＋1タイプ5通り＝15通りしかないので、先に全部書いておき、LINE公式の応答メッセージで自動で返します。届いたメッセージに返信が来たら、余裕のあるときにアオが一言返す、くらいで十分です。

## 4. LINE公式アカウント1つで回す設定

| やること | 設定場所 | 中身 |
|---|---|---|
| あいさつ | あいさつメッセージ | **L0**（診断PDFのリンク入り） |
| 一斉配信 | メッセージ配信 → 予約 | L1〜L12・C0〜C5を、上の日時で予約 |
| 「第1期」への返信 | 応答メッセージ（キーワード「第1期」） | **C0**の3つの吹き出し。10/22より後に送ってきた人にも、初日の案内が届く |
| 特典② | 応答メッセージ（キーワード「タイプ1」〜「タイプ45」） | `type_cards.md` の15通り。2タイプは逆順（「タイプ52」など）も同じ文面で登録 |
| 第1期の人を見分ける | チャット → 「第1期」と送ってきた人に**チャットタグ「第1期」**をつける | 手作業。1日1回まとめてつければ十分 |
| 第1期の人だけに送る | オーディエンス → チャットタグから作る | C0〜C5は、このオーディエンスだけに配信 |
| 購入者に販売の配信を送らない | 一斉配信の「オーディエンスを除外」 | L6〜L12は、「第1期」オーディエンスを除外して配信 |

- 応答メッセージ（自動応答）は、配信の通数に数えられません。一斉配信は数えられるので、料金プランの上限を確認してください
- オーディエンスの作り方・除外のしかたは、管理画面の表示が変わることがあります。予約の前に、テスト配信で確かめてください
- チャットタグがつく前に送られる配信もあるので、L9〜L11の冒頭には「もう購入された方は、読み飛ばしてくださいね」を入れています

## 6. 測るもの

| いつ | 何を | どこで |
|---|---|---|
| 毎日 | 友だち追加数、ブロック数 | LINE公式の管理画面「分析」 |
| 配信ごと | 開封数、リンクのクリック数 | LINE公式の管理画面（メッセージごと） |
| 毎日 | 購入数（**日別で記録**） | noteのダッシュボード |
| 終わったら | 診断の返信率、購入率（購入数÷友だち数）、最終日の購入の割合、「第1期」と送ってきた人数 | 自分で集計 |

「最終日に何割売れたか」は、次のローンチで締め切り前の配信を増やすか減らすかの判断に使います。

## 7. 守ること（この読者向け）

- 値引き・残り枠・カウントダウンで急かさない。締め切りの理由は毎回、言葉で書く
- 恐怖で動かす文章は使わない
- 「買わないを選んでも大丈夫」を、締め切り前の配信に入れる
- 購入者には販売の配信を送らない（オーディエンスで除外）
- 不調が強い人には、ワークより先に医療機関へ、を販売中にも1回は書く（L7）
- 買わなかった人へのお礼（L12）を必ず送り、次からはふだんの役に立つ配信に戻す
