# ローンチ設計：30日ワーク 第1期「一緒に始める30日」

調べた型（`research.md`）を、この商品と読者に合わせて組み直したものです。配信の全文は `line_messages.md`、X投稿は `x_posts.md`。

---

## 1. 全体の流れ（1か月の例）

```
X・Instagram          LINE（見込み客）                         note              購入者LINE
───────────          ─────────────────                        ────              ─────────
告知・物語の投稿  →  友だち追加 → 「お金のクセ診断」を受け取る
                     ↓ 2タイプを返信（任意）
                     教育①②③（3通・6日間）
                     予告
                     発売（6日間）  ──────────────────→  販売記事で購入  →  第1期に参加
                     締め切り（第1期の締め切り）                              15日：全員でDay0
                     お礼（買わなかった人にも）                                 伴走メッセージ（30日）
                                                                              Day30：ふり返り → 個別セッションの案内
```

## 2. オファー

### 第1期「一緒に始める30日」

**締め切りまでに購入した人は、同じ日に、全員でDay0を始めます。** 30日のあいだ、アオから伴走メッセージが届きます。

| 項目 | 内容 |
|---|---|
| 商品 | 30日ワーク（PDF・118ページ）＋書き込みノート＋購入者限定LINE |
| 価格 | 【要確認】（**値引きはしない**。締め切りの前後で同じ価格） |
| 第1期の特典 | ① 30日間の伴走メッセージ（Day0・7・13・20・28・30の6回。つまずきポイントの日に届く）<br>② 【任意・要確認】あなたの2タイプへの、アオからの一言（LINEで1回） |
| 締め切り | 第1期がスタートする日の前日 23:59 |
| 締め切りの理由 | 15日に全員でDay0を始めるため。15日に始めると、**25日の給料日の前に、Day9「先取りを自動にする」が間に合う** |
| 締め切りのあと | ワークは同じ価格で買える。第1期の伴走メッセージだけがつかない |

**この形にした理由**
- 締め切りが「実際に起きる出来事（一斉スタート）」なので、うそがない。値引きの締め切りは景品表示法のリスクがあり、この読者には「急かされた」が残る（`research.md` 4・5）
- ワーク自体が「給料日の10日ほど前に始めると、先取りが次の給料日から動く」と書いている。**日程そのものが、商品の中身と一致する**
- 伴走メッセージは、Day30まで続ける人を増やす。Day30の「ふり返りチェック」まで来る人が増えるほど、個別セッションの申し込みも増える（`product/backend_funnel.md`）
- ②の個別の一言は、喜ばれるが手間がかかる。購入数が読めないうちは、人数か期間に上限をつけるか、なしにする

## 3. 日程表（例：給料日が25日、第1期のスタートが15日）

給料日に合わせて日付をずらしてください。**第1期のスタート（Day0）＝給料日の10日前**、締め切り＝その前日です。

| 日付 | 曜日 | 場所 | 配信 | 目的 |
|---|---|---|---|---|
| 1日〜 | | X・Instagram | 告知と物語の投稿（`x_posts.md`） | LINEに来てもらう |
| 友だち追加時 | | LINE | **L0** あいさつ＋お金のクセ診断（自動） | 自分のタイプを知る小さな体験 |
| 2日 | | LINE | **L1** 教育①「足りない」の正体 | 機会：原因は家で覚えたルール |
| 4日 | | LINE | **L2** 教育② 650円が出せなかった | 変化：アオの物語と、安心ライン |
| 6日 | | LINE | **L3** 教育③ 30日後の、ある1日 | 手に入れた後：3つの習慣と第1期の予告 |
| 8日 | | LINE | **L4** 明日、発売します | 予告と締め切りの理由 |
| 9日 20:00 | | LINE・X | **L5** 発売 | 購入受付スタート |
| 10日 | | LINE | **L6** 中身を、少しだけ | 中身の紹介 |
| 11日 | | LINE | **L7** いただいた質問に答えます | 迷いへの答え |
| 12日 | | LINE | **L8** タイプ別：あなたが特にやること | 自分ごと化 |
| 13日 | | LINE | **L9** 第1期は、あした締め切りです | 締め切りの理由をもう一度 |
| 14日 8:00 | | LINE | **L10** 今日の23:59まで | 当日のお知らせ |
| 14日 20:00 | | LINE・X | **L11** あと4時間です | 最後のお知らせ |
| 15日 | | LINE | **L12** ありがとうございました（全員） | 締め切りの報告とお礼 |
| 15日 | | 購入者LINE | **C0** 第1期、今日からDay0です | 一斉スタート |
| 22日 | | 購入者LINE | **C1** Day7：1週目おつかれさま | 続ける |
| 28日 | | 購入者LINE | **C2** Day13：つまずき①の日 | 止まった人を戻す |
| 翌月4日 | | 購入者LINE | **C3** Day20：つまずき②の日 | 止まった人を戻す |
| 翌月12日 | | 購入者LINE | **C4** Day28：つまずき③の日 | 止まった人を戻す |
| 翌月14日 | | 購入者LINE | **C5** Day30：完成の日 | ふり返りチェック → セッションの案内 |

- ローンチ中のLINE配信は、教育4通＋販売7通＋お礼1通＝**12通**（L0は自動）。教育と販売の比率は約4対6。販売中も、毎回1つは役に立つことを入れて、売り込みだけの配信にしない
- 配信は**21時前後**を基本に（`research.md` 3）。販売開始と最終日だけ時間を固定
- 締め切り前日・当日は、どの配信にも「買わない、を選んでも大丈夫です」を入れる

## 4. 準備リスト（10日前までに）

### 必ずやること
- [ ] 給料日に合わせて、第1期のスタート日と締め切り日を決める
- [ ] noteの販売記事を、締め切り日まで「第1期募集中」と分かる形にする（本文の冒頭か最後に一言。`note/`の本文に追記）
- [ ] noteの有料エリアに「第1期の方は、購入者限定LINEで『第1期』と送ってください」を追記
- [ ] 「お金のクセ診断」PDF（`okane-no-kuse-shindan.pdf`）をGoogleドライブなどに置き、リンクを作る
- [ ] LINE公式のあいさつメッセージに **L0** を設定
- [ ] L1〜L12 を予約配信に入れる（日時を確認）
- [ ] 購入者限定LINEに、キーワード「第1期」の自動応答（C0の要約）を設定。C0〜C5を予約配信
- [ ] 価格を決める（締め切りの前後で変えない）

### ツールがあれば（Lステップ・エルメなど）
- [ ] 診断の返信（2タイプ）でタグをつける → L8をタイプ別に送る
- [ ] 「お休み」と送った人には、販売の配信（L5〜L11）を止める
- [ ] 購入者にタグ → 販売の配信を止める（買った人に「買ってください」を送らない）

LINE公式アカウントだけの場合は、L8を「5タイプ全部入り（自分のタイプだけ読んでください）」で送ります。`line_messages.md` はこの形で書いています。

### あると強いもの
- [ ] 教育①〜③を、noteの無料記事やXの長文投稿にもしておく（途中から友だちになった人が読める）
- [ ] 発売日の夜に、LINEのライブ配信やXのスペースで「30日ワークの始め方」を話す【任意】
- [ ] 診断を返信してくれた人の結果（タイプの割合）を、L7・L8で紹介する（例：「いちばん多かったのは、人に出しすぎタイプでした」）。数字は実際の集計だけを使う

## 5. 測るもの

| いつ | 何を | どこで |
|---|---|---|
| 毎日 | 友だち追加数、ブロック数 | LINE公式の管理画面「分析」 |
| 配信ごと | 開封数、リンクのクリック数 | LINE公式の管理画面（メッセージごと） |
| 毎日 | 購入数（**日別で記録**） | noteのダッシュボード |
| 終わったら | 診断の返信率、購入率（購入数÷友だち数）、最終日の購入の割合 | 自分で集計 |

「最終日に何割売れたか」は、次のローンチで締め切り前の配信を増やすか減らすかの判断に使います。一般的な数字（「半分が最終日」など）は根拠が弱いので、自分の数字で決めてください。

## 6. 守ること（この読者向け）

- 値引き・残り枠・カウントダウンで急かさない。締め切りの理由は毎回、言葉で書く
- 「このままだと、ずっと…」のような、恐怖で動かす文章は使わない
- 「買わないを選んでも大丈夫」を、販売中の配信に毎回入れる
- 買った人には、販売の配信を送らない（ツールがない場合は、L9以降の冒頭に「もう購入された方は、この配信は読み飛ばしてください」）
- 不調が強い人には、ワークより先に医療機関へ、を販売中にも1回は書く
- 買わなかった人へのお礼（L12）を必ず送る。次の配信からは、ふだんの役に立つ配信に戻す
