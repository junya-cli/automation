# ローンチ設計：30日ワーク 第1期「一緒に始める30日」

調べた型（`research.md`）を、この商品と読者に合わせて組み直したものです。配信と自動応答の全文は `line_messages.md`、X投稿は `x_posts.md`、第1期特典の文面は `type_cards.md`。

## 正直に：この配信で「確実に」売れるか

**確実に売れる、とは言えません。** どんな配信でも保証はできません。

売上は **「届いた人数 × 開封 × クリック × 購入」** の掛け算です。文章で上げられるのは後ろの3つで、いちばん効くのは**届いた人数**です。購入率が同じなら、友だちが2倍になれば売上も2倍になります。

そこで、売れない原因になる穴を洗い出して、次のように直しました。

| 穴 | 何が起きるか | 直したこと |
|---|---|---|
| **通数の上限** | 無料プラン（月200通）だと、友だち17人以上で全部は送れない。上限に来た月は、それ以上送れない | 0章で、友だち数ごとに必要なプランを計算。足りないとき用に「節約版」（6回）を用意 |
| **もともといる友だちに診断が届いていない** | 診断はあいさつ（友だち追加のとき）でしか届かない。L1の「診断、やってみましたか？」が通じない | L1で「診断」と送ってもらい、自動応答で渡す（通数に数えない） |
| **画像を入れると吹き出しが4つ** | 1回の配信は吹き出し3つまで（画像も1つに数える）。L3・L5・L6・L8は、そのままでは送れなかった | すべて3つ以内に組み直した（`make_launch.py` が毎回確かめる） |
| **通知に出る1行目** | 全部「こんばんは、アオです。」で始まっていて、通知を見ても中身が分からない | 1行目に中身を書き、あいさつは2行目へ |
| **購入した人が販売の配信を受け取り続ける** | 「第1期」と送ってもらわないとタグがつけられない。発売の配信（L5）に、その案内がなかった | 販売中のすべての配信に「購入したら『第1期』と送ってください」 |
| **Day0の前に「今日からDay0」と返してしまう** | 「第1期」の自動応答をC0にしていたので、10/16に買った人にも「今日から、Day0です」が届く | Day0の前用の返事（A3）をつくり、10/22の朝にC0の文面（A4）へ切り替える |
| **途中から来た人** | 10/10より後に友だちになった人は、教育①〜③を読んでいない | 「まとめ」と送ると要約が届く（A2）。あいさつ（L0）で案内 |
| **予告の「急がなくて大丈夫です」** | 締め切りの理由を書いた直後に、締め切りを打ち消していた | 消して、「一緒に始めたい方は、明日20時のお知らせを」に |
| **試してから決められない** | 中身を見せるだけで、やってみる場面がなかった | 販売中にDay1を体験してもらう（L6）。Day1のページの画像つき |
| **声がない** | 受講者の声がないまま「本当にできる？」に答えていなかった | 「初めての発売なので、まだありません」と正直に答える（L7）。Day30で、許可をとって感想を集める（C5） |
| **リンクが文字だけ** | 押せる場所が小さい | 発売と締め切りの配信に、タップするとnoteが開く画像（リッチメッセージ）を入れる |
| **迷っている人と話す場面がない** | 一斉配信だけで終わる | L7・L9で「迷っている理由を1つ送ってください。直接お返事します」 |
| **X投稿が少ない** | LINEにつながる投稿が3本だけ | 20本に（LINEへ11本・noteへ7本）。発売までは毎日LINE（診断）へ、発売からは毎日noteへ |

残る一番大きな変数は、**LINEの友だち数**です。ここは文章では増やせないので、5章の「集める」を、発売の前日までに必ずやってください。

## 0. 配信の前に、必ず確認すること（10/9まで）

### 0-1. 通数（いちばん大事）

LINE公式は、**「1回の配信 × 届いた人数」** を1か月の通数として数えます（吹き出し3つまでで1回）。あいさつメッセージ・応答メッセージ（自動応答）は数えません。

| プラン | 月額（税別） | 1か月に送れる数 | 上限を超えたら |
|---|---|---|---|
| コミュニケーション | 0円 | 200通 | 送れない |
| ライト | 5,000円 | 5,000通 | 送れない |
| スタンダード | 15,000円 | 30,000通 | 1通3円で追加（2026年10月の改定後） |

10月に送る数は、次のとおりです（友だち数＝管理画面の「ターゲットリーチ」。ブロックした人は数えない）。

| | 一斉配信 | 10月の通数 |
|---|---|---|
| **全部** | L1〜L12（12回） | 友だち数 × 12 |
| **節約版** | L1・L2・L3・L5・L9・L11（「必須」の6回） | 友だち数 × 6 |

第1期の人への配信（C0・C1は10月、C2〜C5は11月）は、第1期の人数 × 回数だけです。

| 友だち数 | 全部 | 節約版 |
|---|---|---|
| 〜16人 | 無料プランでOK | 無料プランでOK |
| 17〜33人 | ライトが必要 | 無料プランでOK |
| 34〜416人 | ライト | ライト |
| 417〜833人 | スタンダード | ライト |
| 834〜2,500人 | スタンダード | スタンダード |

- ローンチ中に友だちが増えるので、**2割ほど余裕を見てください**。10月にすでに送った分も数に入ります
- ライトの月額は、ワーク2冊分ほどです。全部送る価値があるかは、友だち数で決めてください
- プランの変え方・いつから変わるかは、管理画面の案内で確かめてください

**節約版のとき**は、「できれば」の配信（L4・L6・L7・L8・L10・L12）を送りません。L3の「次の配信でお知らせします」は、そのままL5（発売）につながるように書いてあります。L5とL9に、第1期の理由・価格・締め切りを全部入れてあります。余裕があれば、L12（お礼）だけは送ってください。

### 0-2. 応答の設定

- **チャット**と**応答メッセージ**を、両方オンにする（自動応答と、手で返信するチャットを両方使うため）
- 最初から入っている「個別にはお返事できません」のような応答メッセージがオンなら、**オフにする**。この配信では診断の結果や迷いを送ってもらうので、そのたびに冷たい返事が届いてしまいます
- 自分のスマホから「診断」「まとめ」「タイプ25」と送って、自動で返ってくるか確かめる

### 0-3. 通知の見え方

L1を予約する前に、**テスト配信**で自分のスマホに送り、ロック画面の通知とトーク一覧に何が出るかを見てください。どの吹き出しが出ても意味が通るように、1行目と最後の吹き出しを書いてあります。

## 4. LINE公式アカウント1つで回す設定

| やること | 設定場所 | 中身 |
|---|---|---|
| あいさつ | あいさつメッセージ | 10/8〜：**L0**（診断＋「まとめ」の案内）。10/22の朝に **L0n** に戻す |
| 一斉配信 | メッセージ配信 → 予約 | 上の日時で予約。節約版なら「必須」だけ |
| 自動応答 | 応答メッセージ（キーワード） | A1〜A4、タイプ1〜45。キーワードは完全一致なので、全角も登録する |
| リッチメッセージ | リッチメッセージ → 作成 | 画像（`launch/images/rich_hatsubai.png`・`rich_shimekiri.png`、1040×1040）を入れ、タップしたときのリンクにnoteのURL。タイトルは `line_messages.md` のとおり（通知とトーク一覧に出る）。配信の作成画面で、吹き出しの1つとして選ぶ |
| 第1期の人を見分ける | チャット → 「第1期」と送ってきた人に**チャットタグ「第1期」**をつける | 手作業。1日1回まとめてで十分 |
| 第1期の人だけに送る | オーディエンス → チャットタグから作る | C0〜C5は、このオーディエンスだけに配信 |
| 購入者に販売の配信を送らない | 一斉配信の「オーディエンスを除外」 | L6〜L12は、「第1期」オーディエンスを除外して配信 |

**うまくいかないときの代わり**
- チャットタグのオーディエンスが、人数が少なくて配信に使えないとき（下限は公式に確認できていません）：
  - L6〜L12：除外せずに全員に送る。冒頭や最後に「購入済みの方は、読み飛ばしてください」が入っています
  - C0〜C5：第1期の人に、**チャットで1人ずつ**送る（台本からコピー）。チャットで送るメッセージは通数に数えない扱いと案内されていますが、念のため管理画面の利用状況で確かめてください
- オーディエンスの作り方・除外のしかたは、管理画面の表示が変わることがあります。予約の前に、テスト配信で確かめてください

| 配信数（届いた数） | 友だち数より大きく少ない | 通数の上限・ブロックを確認。ブロックが増えた配信の次は、「できれば」の配信を1つ減らす |
| 開封率（開封数 ÷ 配信数） | ふだんの配信より低い | 次の配信の1行目を変える。時間を変える（21時 → 20時など） |
| クリック率（クリック数 ÷ 開封数） | L5のあと、クリックが少ない | リンクを吹き出しの上の方へ。リッチメッセージを使う |
| 購入率（購入数 ÷ 記事のビュー） | クリックはあるのに買われない | noteの無料部分（価格・中身・よくある質問）を見直す。L7・L9の返信で届いた迷いに、記事のQ&Aで答える |

- 見る日：**10/17の朝**（発売の夜の結果）、10/19の朝、10/21の朝
- くらべる相手は、ほかの人の数字ではなく、**あなたのふだんの配信**です
- 1回に直すのは1か所だけ（どれが効いたか分かるように）
- 購入数は**日別で記録**する。「最終日に何割売れたか」は、次のローンチで締め切り前の配信を増やすか減らすかの判断に使います

## 7. 守ること（この読者向け）

- 値引き・残り枠・カウントダウンで急かさない。締め切りの理由は毎回、言葉で書く
- 恐怖で動かす文章は使わない
- 「買わないを選んでも大丈夫」を、締め切り前の配信に入れる（売上を増やす言葉としては、あてにしない。`research.md` の7章）
- 23時より遅い時間には送らない（最後のお知らせは20時のL11）
- 購入者には販売の配信を送らない（オーディエンスで除外）
- 不調が強い人には、ワークより先に医療機関へ、を販売中にも1回は書く（L7。節約版ではnoteの本文に同じことが書いてあります）
- 受講者の声は、本人の許可をとったものだけを使う。作らない
- 買わなかった人へのお礼（L12）を、できるだけ送り、次からはふだんの役に立つ配信に戻す
