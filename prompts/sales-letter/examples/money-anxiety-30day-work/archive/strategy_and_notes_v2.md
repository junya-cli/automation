## 1. 戦略シート（要約）

**目的**：購入。副目的は購入者限定LINEへの登録（商品内で案内済み）。

**「誰が」**：アオさん自身がACの当事者で、250人と向き合ってきた。体験談（研究職・残高5万円・650円のラーメン・1,500円のお寿司）が具体的で強い。→ 自己紹介は短めにし、中盤のストーリーで厚くする。

**2段手前のつまずき**
- 読者が思う原因：収入が少ない／節約できない／家計簿が続かない／自分がだらしない
- 1段手前：お金の流れを見ていない（見るのが怖い）、「十分」のラインがない
- **2段手前：お金の不安を「自分の性格の問題」だと思って、自分を責めている**
- → レターの最初の仕事は「あなたのせいではない」と原因を置き換えること。

**本音の欲望（建前 → 本音）**

| 建前 | 本音 |
|---|---|
| 貯金を増やしたい | 残高を見ても、胸がざわつかない自分になりたい |
| 節約したい | 我慢しないで、自分のために使っても大丈夫だと思いたい |
| 家計簿を続けたい | お金のことを、毎日考えなくていいようになりたい |
| 親のことを整理したい | 親と向き合わずに、親の影から自由になりたい |
| （言葉にしていない） | お金のことで、もう自分を責めたくない |

**言葉の裏のイメージ（消すべきマイナス）**
- 家計簿・節約 → 続かない、つらい、我慢 → 「毎日の家計簿はつけない、我慢の節約もしない」を冒頭で宣言
- 毒親・AC系の本 → 重い、親と向き合わされる、泣かされる → 「親を許さなくていい」「つらい日は飛ばしていい」
- お金の勉強 → 難しい → 「1日5分」「3つの習慣だけ」

**コンセプト**：お金の不安は、額ではなく「家で覚えた『足りない』という解釈」。だから稼ぐのでも節約でもなく、30日・3つの小さな習慣でほどく。
- 30秒テスト：「家計簿も節約もせず、親とも向き合わずに、1日5分でお金の不安が軽くなるワーク」→ 読者にとっての「それが本当なら欲しい」は強い。
- 成功要因：意志や我慢ではなく「仕組み（自動・週1回・1文）」と「クセの正体を知ること」。

**黄金方程式**

| 要素 | この商品では |
|---|---|
| 問題 | 収入はあるのに、いつも「足りない」。残高を見られない、自分に使えない、まとめ買いして落ち込む。そして自分を責める |
| 原因 | 額ではなく「足りない」という解釈。それは家で見て覚えたもの。しかも「見ていない」「十分のラインがない」から消えない |
| 解決 | 見る・分ける・ひと呼吸の3つの習慣。心（クセ）と財布（仕組み）を同時に扱う |
| 証拠 | 研究（資産100万ドル以上でも74.5%が「2倍以上必要」、マシュマロ実験の続き、自動加入で37%→86% など）、アオさんの体験、250人のセッション、【要証拠：受講者の声】 |
| 理想 | 給料日の翌日に自動で「非常口」にお金が移る。週1回5分以外はお金のことを考えなくていい。800円の朝ごはんを罪悪感なしで |
| オファー | 30日後に手元に残る3つ（自分のクセ・出口の数字・余裕プラン1枚） |

**世界の二分化**：「十分」のラインがある人／ない人。
**地獄のシナリオ**：煽らず、研究の事実で描く（収入や貯金が増えても「足りない」は同じ形でついてくる）。

**冒頭の切り口**：悩みの言い当て（給料日の夜に残高アプリを開けない）→ 常識破壊（家計簿も節約もしない、親を許さなくていい）。

### この読者に合わせて、マスタープロンプトから調整した点

| マスタープロンプトの技法 | 調整 | 理由 |
|---|---|---|
| スクリーニングで「向いていない人」に負のラベルを貼る | v2では「買って欲しくない人」を設けない。対象を広げ、迷いそうな人には「よくある質問」で使い方を答える | お金を見直したい人なら誰が買ってもよい商品だから。負のラベルは、自分を責めるクセを持つ読者には逆効果 |
| 地獄のシナリオ・恐怖で動かす | 研究の事実だけで静かに描いた。「子どもに連鎖する」のような罪悪感をあおる表現は使っていない | 不安の強い読者を恐怖で動かすと、購入後の信頼を失う |
| 無双感・「〇〇できてしまう」 | 「余裕感」に置き換えた（残高を見てもざわつかない、通知が勝手に届く） | 商品のトーン（静か・やさしい）に合わせるため |
| 締めの自己啓発でモチベを最大に | 「もう自分を責めなくていい」「自分で選んで」と、商品の言葉で締めた | 読者を急かさず、自分で決めた決断の方が揺らがない |
| 「今」動く理由 | 締切ではなく「今日をDay0（区切りの日）に」と、研究（Dai ほか, 2014）を根拠にした | 架空の限定・締切は使わない |

## 5. 【要証拠】【要確認】リスト

**差し替えが必要な素材**
- 【要証拠】受講者・モニターの声（上位2タイプ、不安メーターのDay0→Day30、いちばん変わったこと）。**現状いちばんの弱点**
- 【要証拠】セッション受講者の声（掲載許可のあるもの）
- 【要確認】セッションで実際によく聞く「お金の言葉」（本文「はじめまして、アオです」の節に入れると強い）
- 【要確認】価格、販売場所、返金保証の有無

**アオさん本人に確認したいこと**
- 家族の話（両親が揉めていた、父が怒鳴っていた、言われた言葉）を、購入前の公開ページに載せてよいか。PDF内では購入者向けに書かれている内容のため
- **【最重要】物語の差し込み枠**：「2つの出会い」のあと、アオさんが実際にやったことを1〜2行（例：「それから僕は、〇〇を始めました」）。このワークの3つの習慣を自分でもやっていたなら、そう書けるのが一番強い
- ストーリー内で私が補った箇所が、本人の実感と合っているか
  - 「なんで、たった650円で、こんなに胸がぎゅっとするんだろう。」
  - 「あの頃の言葉が、大人になった僕の財布の中で、まだ鳴っていたんです。」
  - 「お金のクセも、僕の性格ではなく、家で覚えたルールなのかもしれない、と思えました。」（ACという言葉に出会ったときの気づき）
  - 「僕の『足りない』は、お金の額だけではなく、お金の"見方"の問題なのかもしれない、と気づきました。」（メンターの一言のあと）
  - 2つの出会いの順番（ACの言葉 → メンターの一言）が事実どおりか
- 一人称・文体（PDFと同じ「僕」・です・ます調で書いています）

**事実・表現の確認**
- 74.5%（資産100万ドル以上）／約7割（資産1,000万ドル以上）の数字と説明：テキスト化したPDFでレイアウトが崩れていたため、元PDFの記述と照合を
- 引用している研究の年・著者名が元PDFと一致しているか（Donnelly 2018、Kidd 2013、Madrian & Shea 2001、Sheeran 2025、Lally 2010、Dai 2014、Drexler 2014、J-FLEC 2025）
- タイトルの「お金の不安が**なくなる**」は効果の断定に読まれる可能性がある。本文では「なくなる」と約束せず、「軽くなる」「30日後に手元に残るもの」で書いている。タイトル自体を変えるかはご判断を
- 心理的な効果について：本文に「治療ではない」「先に専門窓口へ」を明記済み。治る・改善するといった表現は使っていない
- 購入者限定LINEの「壁」の案内の先に有料サービス（個別セッション等）がある場合は、販売ページでもその旨を一言書いておくと、購入後の不信感を防げる
- 第三者に紹介・感想投稿を依頼する場合はPR表記（ステマ規制）

## 6. レターより効く打ち手（インパクト順）

1. **モニターを募集して、声と数字を集める**
