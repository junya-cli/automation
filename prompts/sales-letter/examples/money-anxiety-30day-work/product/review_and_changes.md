# 商品の評価と、v2での変更一覧
## 毒親育ちのお金の不安がなくなる小さな習慣（30日ワーク）

## 1. 率直な評価

**中身は良い。ただ、言葉が硬く、売りにくく、バックエンドへの導線が曖昧。**

| 観点 | 評価 | ひとこと |
|---|---|---|
| 中身の誠実さ・根拠 | ◎ | 方法ごとに研究の根拠があり、言い過ぎを自分で正している（「95%は無意識」は測られていない、など）。同ジャンルの商品の中でかなり丁寧 |
| 読者への配慮 | ◎ | 責めない、親を許さなくていい、つらい日は飛ばしていい、スキップ券、7日コース、医療への相談の目安。不安の強い読者向けとして安全設計が良い |
| 成果物の具体性 | ◯ | 5タイプ、余裕プラン1枚、一言カード、不安メーター3回。「30日後に何が残るか」がはっきりしている |
| わかりやすさ | △ | 「壁」「出口」「解釈」「上位2タイプ」「印メモ」「山場」など、読者が一瞬止まる言葉が約90か所ある |
| 入りやすさ | △ | 「1日5分」と言いながら、Day0までに第1・2章（約15分）を読む必要がある。それが書いてあるのは5ページ目 |
| 成功事例 | × | 「このワークで変わった人」の声や事例がワーク内にもない。セッションに案内するときの説得材料もない |
| タイトルと中身のズレ | △ | タイトルは「不安がなくなる」。中身は「30日はいちばん大変な最初の上り坂（習慣化は66日）」と正直に書いている。約束が強すぎる |
| バックエンドへの導線 | × | 意図はある（3つの壁、同じ一文を3回、LINEで「壁」）。でも、何に案内されるのか、有料なのか、誰向けなのかが分からない。同じ決め文句の繰り返しは、売り込みの気配だけが残る |

### いちばん大きい問題：導線が「匂わせ」で止まっている

元の版では、Day13・Day20・Day28の3か所が、すべて同じ一文で終わっています。
> そこは、一人だと見えにくい場所です。

そしてDay30で「いちばん高かった壁の先を、一緒に見てみたい方へ。LINEで『壁』と送ってください」。

読者からすると、
- 「壁」が何のことか分からない（ワークの用語なのか、心の問題なのか）
- 送ったら何が来るのか、有料なのか分からない
- 同じ一文が3回出てくるので、「何か売られるのかな」という警戒だけが残る

**v2では、誰に・なぜ・何を案内するのかを正直に書き、本人が自分で判定できるチェック（Day30の「30日のふり返りチェック」）を置きました。**

## 2. 用語の置き換え表

| 旧 | 新 | 理由 |
|---|---|---|
| 3つの壁／壁①②③ | 3つの**つまずきポイント**／つまずき①②③ | 「壁」は抽象的で、心の問題なのかワークの難所なのか分からない |
| いちばん高かった壁 | いちばん止まったつまずきポイント | 同上 |
| LINEで「壁」と送る | LINEで「**セッション**」と送る | 何が届くのかを言葉で分かるようにする |
| 見えない出口4つ／出口1〜4 | お金の**「もれ口」**4つ／もれ口1〜4 | 「出口」はお金が出ていく場所に聞こえにくい。「もれ口」なら気づかないうちに漏れるイメージになる |
| 解釈 | **受け止め方**／思い込み | 「解釈」は硬い。メンターの発言の直接引用だけは残し、すぐ後に言い換えを添えた |
| 事実の不安／解釈の不安 | **本当に足りない不安／足りない気がする不安** | 何が違うのか、言葉だけで分かるようにする |
| 「ここまであれば大丈夫」のライン／ライン | **安心ライン**（ここまであれば大丈夫、という金額） | 名前をつけて、何度出てきても同じものだと分かるようにする |
| 上位2タイプ | **あなたの2タイプ**（点数が高い2つ） | 「上位」がランキングのようで分かりにくい |
| 気持ちの印メモ／印メモ | **色分けメモ** | 何をするメモかが名前で分かる |
| 区切りの日 | **スタートの日** | 「区切り」が何の区切りか伝わりにくい。研究の説明（区切りのあとに始めやすい）は「なぜ？」に残した |
| 山場：自分に使う日 | **いちばん大事な日**：自分に使う | 「山場」は物語の言葉で、何をする日か伝わりにくい |
| 見積もりのクセ | **少なめに見積もるクセ** | どんなクセかを名前に入れる |
| 特別費 | 特別費（**年に数回の出費**） | 初出と見出しで中身を添える |
| 「もし〜なら〜する」 | **もしもの一文**（「もし〜になったら、〜する」と先に決めておく1文） | 名前があると、Day29や余裕プランで呼びやすい |
| 先取り | 先取り（**給料日に、使う前に先に取り分けること**） | 初出で意味を添える |
| やってはいけない罠 | **やりがちな落とし穴** | 「罠」は責められている感じがする |
| 予定された小さな楽しみ | 予定に入れた小さな楽しみ | 受け身の言い回しをやめる |
| J-FLEC | 金融経済教育推進機構（J-FLEC） | 初出で正式名を添える |
| ほどく | ほどく（**家で覚えたお金の口ぐせに気づいて、少しずつゆるめる**） | 進め方の表で意味を添える |

## 4. ほかに検討してほしいこと

1. **タイトルの「なくなる」**
   ワーク自身が「30日は最初の上り坂」と書いているので、約束が強すぎます。さらに、Day30に「変わらなかった人へ」のページを置くと、「なくなるって書いてあったのに」と矛盾が目立ちます。「お金の不安が**軽くなる**小さな習慣」「お金の不安を**ほどく**30日ワーク」などを検討してください。
2. **事例を入れる**
   ワーク内に、モニターの「Day0 → Day30」の変化を1〜2例（匿名・許可あり）入れると、続ける力にも、セッションへの信頼にもなります。
3. **セッション名の「克服」**
   ワーク自身が「アダルトチルドレンは病名ではない」と書いているので、「克服」は「病気を治す」と受け取られないよう、案内文で「治療ではない」を必ず添えてください（v2では添えています）。
