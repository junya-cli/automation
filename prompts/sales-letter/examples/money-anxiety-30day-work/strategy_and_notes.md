## 1. 戦略シート（要約）

**目的**：ワークの購入。セッションは売らない（存在を正直に知らせるだけ）。購入後の導線は商品内とLINEが担当（`product/backend_funnel.md`）。

**「誰が」**：アオさん自身がACの当事者で、250人と1対1で向き合ってきた。体験談（研究職・残高5万円・650円のラーメン・1,500円のお寿司）が具体的。→ 自己紹介は短く、物語を中盤で厚く。

**2段手前のつまずき**
- 読者が思う原因：収入が少ない／自分がだらしない／家計簿が続かない
- 1段手前：お金の流れを見ていない（見るのが怖い）、安心ラインがない
- 2段手前：**自分の不安が「本当に足りない」のか「足りない気がする」のか、確かめたことがない。そして、確かめられないのは家で覚えたルールのせいなのに、性格のせいだと思っている**

**本音の欲望**

| 建前 | 本音 |
|---|---|
| 貯金を増やしたい | 残高を見ても、胸がざわつかない自分になりたい |
| 節約したい | 我慢しないで、自分のために使っても大丈夫だと思いたい |
| 家計簿を続けたい | お金のことを、毎日考えなくていいようになりたい |
| 親のことを整理したい | 親と向き合わずに、親の影から自由になりたい |
| （言葉にしていない） | お金のことで、もう自分を責めたくない |

**コンセプト**：お金の問題に見えて、家のルールの問題。だから、心（クセ）と財布（仕組み）を同時に、1日5分でほどく。
- 30秒版：「家計簿も節約もせず、親とも向き合わずに、1日5分で『足りない』をほどく30日ワーク」
- 「〇〇が全て」：**安心ライン**（ここまであれば大丈夫、という自分の数字）。世界の二分化も「安心ラインがある人／ない人」

**黄金方程式**

| 要素 | この商品では |
|---|---|
| 問題 | 大きな買い物はしていないのに、いつも「足りない」。自分には使えず、頼まれると断れず、残高を見られない |
| 原因 | 「足りない」には2種類あるのに、見られないから確かめられない。見られないのは家で覚えたルールのせい。さらに、4つのもれ口と、安心ラインの不在 |
| 解決 | 見る・分ける・ひと呼吸。中身は伏せる（「あること」「もう1つの目的」「1文だけ」） |
| 証拠 | 研究（74.5%、15.2%、27.8%、マシュマロ、15〜20%、約半分、642件 など）、アオさんの体験、250人、**実物ページ**、【要証拠：受講者の声】 |
| 理想 | 給料日の翌日に安心ボックスへ自動で移る。週1回5分以外は考えなくていい。罪悪感なしのパン屋さんの朝ごはん。残高を見てもざわつかない |
| オファー | 30日後に残る3つ（2タイプ・もれ口と金額・余裕プラン1枚）＋今日のうちに2タイプが分かる |

**この読者に合わせた調整（v2から継続）**
- 「向いていない人」に負のラベルを貼らない（自分を責めるクセのある読者には逆効果）
- 地獄のシナリオは研究の事実だけで静かに描く。罪悪感をあおる表現は使わない
- 「無双感」は「余裕感」に置き換える
- 「今」動く理由は、架空の締切ではなく「今日をDay0に」「今日のうちに2タイプが分かる」「給料日の10日前に始めると次の給料日から動く」

## 4. 別案

### 冒頭フック ×5（A/Bテスト用）

1. **矛盾の言い当て（採用）**：「自分のための800円は、レジの前で、迷う。なのに、親に頼まれたお金は、理由も聞かずに、振り込んでいる。」

5. **やさしい問いかけ**：「『ここまであれば、今月は大丈夫』。その金額を、あなたは今すぐ言えますか？」

### タイトル案 ×5

1. 自分のための800円は迷うのに、親に頼まれたお金は振り込めてしまうあなたへ｜毒親育ちのお金の不安がなくなる小さな習慣
2. あなたの「足りない」は、本当に足りない？それとも、家で覚えた"気がする"？｜1日5分・30日ワーク
3. 毎日の家計簿も、我慢の節約もしない。親も許さなくていい。1日5分の30日ワーク
4. 「使ってないのにお金がない」の正体は、4つのもれ口と、家で覚えたルールだった
5. 自分のための650円が出せなかった僕が、残高を見てもざわつかなくなるまで

## 5. 【要証拠】【要確認】リスト
